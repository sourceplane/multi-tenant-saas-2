# webhook-verifier

Zero-dependency HMAC-SHA256 verifier for outbound webhook deliveries, on WebCrypto alone so it runs verbatim on Workers, Bun, Node and browsers.

A shared package of the multi-tenant-saas-2 workspace, consumed by the components
below at build time.

## Depended on by

- **cli** — First-class TypeScript CLI for the Multi Tenant Saas 2 control plane API
